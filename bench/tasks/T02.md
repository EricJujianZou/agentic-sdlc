# T02 — Monthly per-category summary

**Motivation:** A single monthly total is too coarse; users want a category
breakdown per month.

**Required behavior:**

1. Add `report.monthly_summary(ledger, year: int, month: int) -> dict[str, float]`
   in `ledgerlite/report.py`.
2. It returns a mapping of category -> total amount for entries whose date falls
   in the given calendar month (same month selection as `report.month_total`).
3. Categories with no entries in that month must NOT appear in the dict; an
   empty month returns `{}`.
4. Entries with the default category appear under the key `"uncategorized"`.
5. `sum(monthly_summary(...).values())` must equal `month_total(...)` for the
   same month.

**Verified by:** `bench/target/tests/test_t02.py`
