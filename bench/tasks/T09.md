# T09 — Query / filter API

**Motivation:** "How much did I spend on coffee in March?" needs filtering,
not manual loops.

**Required behavior:**

1. `Ledger.query(self, category=None, date_from=None, date_to=None,
   text=None) -> list[Entry]`.
2. All given filters are AND-combined; omitted filters do not restrict.
   `query()` with no arguments returns all entries.
3. `category`: exact match on `entry.category`.
4. `date_from` / `date_to`: inclusive bounds on the entry date. Bound strings
   must be normalized the same way entry dates are (T03), so `"2026-3-5"`
   works as a bound.
5. `text`: case-insensitive substring match against the entry note.
6. Results are returned in date-sorted order (same order as
   `Ledger.entries()`).

**Verified by:** `bench/target/tests/test_t09.py`
