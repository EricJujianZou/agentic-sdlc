# T07 — Recurring entries

**Motivation:** Subscriptions repeat monthly; users should not have to type
them twelve times.

**Required behavior:**

1. `Ledger.add_recurring(self, entry: Entry, months: int) -> None` adds
   `months` entries to the ledger: one for the entry's own date, then one per
   following calendar month.
2. Each generated entry keeps the template's amount, category and note; only
   the date changes.
3. The day-of-month is preserved. When a following month is too short, clamp
   to that month's last day (e.g. starting 2026-01-31 for 3 months yields
   2026-01-31, 2026-02-28, 2026-03-31; leap years must be respected via
   `calendar`/`datetime` from the stdlib).
4. Year rollover works (2026-11-15 for 3 months yields 2026-11-15, 2026-12-15,
   2027-01-15).
5. `months=1` is equivalent to a single `add`.

**Verified by:** `bench/target/tests/test_t07.py`
