# T01 — Categories

**Motivation:** Users want to know *what* they spend on, not just how much.

**Required behavior:**

1. `Entry` (in `ledgerlite/ledger.py`) gains a new field `category: str` with
   default `"uncategorized"`. Existing positional usage `Entry(date, amount, note)`
   must keep working; `category` may be passed by keyword.
2. `Ledger` gains `totals_by_category(self) -> dict[str, float]` mapping each
   category present in the ledger to the sum of its entry amounts.
3. `storage.save` / `storage.load` must round-trip the category: the JSON entry
   objects gain a `"category"` key, and `load` restores it (defaulting to
   `"uncategorized"` for old files without the key).
4. CLI: the `add` subcommand gains `--category` (default `"uncategorized"`),
   and `list` output includes each entry's category on its line.

**Verified by:** `bench/target/tests/test_t01.py`
