# T05 — CSV export

**Motivation:** Users want to open their ledger in a spreadsheet.

**Required behavior:**

1. Add `storage.export_csv(ledger, path: str) -> None` in
   `ledgerlite/storage.py`, using only the stdlib `csv` module.
2. Column order (header row required, exactly these names):
   `date,amount,category,note`.
3. One row per entry, sorted by date ascending (the `Ledger.entries()` order).
4. `amount` is formatted with exactly two decimal places (e.g. `40.00`,
   `7.25`).
5. An empty ledger exports a file containing only the header row.
6. Write with `newline=""` semantics so the file has no blank lines between
   rows on Windows.

**Verified by:** `bench/target/tests/test_t05.py`
