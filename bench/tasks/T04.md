# T04 — Per-category budgets

**Motivation:** Users want to cap monthly spending per category and be warned
when they blow past a cap.

**Required behavior:**

1. `Ledger.set_budget(self, category: str, limit: float) -> None` records a
   monthly budget for a category. `Ledger.budgets` exposes the current mapping
   `dict[str, float]` (setting the same category again overwrites).
2. `report.budget_warnings(ledger, year: int, month: int) -> dict[str, float]`
   returns, for each budgeted category whose spending in that month EXCEEDS its
   limit, the overage amount (`spent - limit`). Categories at or under budget,
   and categories without a budget, are omitted. Empty result is `{}`.
3. Spending per category/month is defined exactly as in
   `report.monthly_summary` (T02).
4. `storage.save` / `storage.load` persist budgets (a `"budgets"` object in the
   JSON; old files without it load with no budgets).

**Verified by:** `bench/target/tests/test_t04.py`
