# T34: Audit trail for every change

Several people work the stockroom now and we can't tell who changed what.
We want an event log kept with the data:

- Every operation that changes anything (add-item, add-supplier, receive, ship,
  transfer, place-order, receive-order, cancel-order, set-price, imports, ...)
  appends exactly one entry to the log.
- Each entry records: `op` — the command name as spelled on the CLI (e.g.
  "receive", "place-order"); `args` — a mapping of the operation's arguments
  (sku, qty, order id, ...); `actor` — whatever `--actor` was given, otherwise
  empty/None; and a timestamp.
- Reports and exports change nothing, so they log nothing.
- The log is saved with the state and survives reload; scripts read it as
  `store.events`, a list of dicts, oldest first.
- Changes made through the library directly (e.g. `store.receive(sku, qty)`
  followed by a save) are logged the same way, just with no actor.

Acceptance: one entry per change, in the order the changes happened.
