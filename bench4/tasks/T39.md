# T39: Export the audit trail to CSV

Our bookkeeper wants the event log in a spreadsheet.

`export-events <path> [--op NAME] [--since YYYY-MM-DD]` writes the event log to
a CSV file:

- Header row `ts,op,actor,args`; one row per event, oldest first. The `args`
  cell is the event's argument mapping JSON-encoded; an event with no actor
  gets an empty cell.
- `--op` keeps only events whose op matches exactly ("receive" must not match
  "receive-order").
- `--since` keeps only events whose timestamp falls on or after the given date
  (inclusive).
- The two filters combine. A filter that matches nothing still writes the
  header row. The command prints how many events it exported and exits 0.
