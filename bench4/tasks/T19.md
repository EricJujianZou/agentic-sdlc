# T19 — CSV needs to carry warehouse info

We exchange stock lists with our suppliers as CSV, and since the second
warehouse opened those files have been ambiguous about where stock is.

What I want:

- Export: the header gains a `warehouse` column. Write one row per
  warehouse in which an item holds stock, with `qty` being that
  warehouse's count. An item with no stock anywhere still exports a single
  row with warehouse `main` and qty 0. The `category` column stays.
- Import: files WITH a `warehouse` column set that warehouse's quantity
  for the SKU (several rows for one SKU, different warehouses, all apply).
  Older files still work exactly as before: files with a category column
  but no warehouse column, and the original files with neither — their
  quantities land in `main`, and items from the original format get
  category `uncategorized` as they do today.
- Import must be header-driven: the order of columns in the file must not
  matter.
- Round-trip: exporting and then importing into a fresh store reproduces
  the same per-warehouse quantities and categories.
