# T46 — Batch dry-run

The Monday batch (the CSV apply you built for us) is great, but we would
like to preview a sheet before committing it. Add a `--dry-run` option:

`stockroom --data DIR batch FILE.csv --dry-run`

- Prints one line per row describing what WOULD be done (mentioning at
  least the op and the SKU), then a closing line containing "dry-run" and
  the row count.
- Validates exactly like a real run: if some row would fail, report the
  same `error: batch failed at row N: <reason>` message and exit 1;
  otherwise exit 0.
- Guarantee: a dry run never changes anything. Every file in the data
  directory must be untouched — same content AND same modification time (we
  watch mtimes for our backup tooling) — whether the sheet was valid or not.
- A real run right after a dry run must behave exactly as if the dry run
  had never happened.
