# T03 — Bug: order missing from the monthly report

Yesterday I placed an order with `place-order WID-1 20 --date 2026-1-5`.
The command succeeded and the order shows up fine in
`report history WID-1`. But `report monthly 2026-01` does not list it,
and the order count at the bottom of that report is short.

A colleague types dates without the leading zeros all the time, so a
number of our January orders are affected — the monthly totals have been
quietly wrong.

Expected: an order placed on 2026-1-5 counts toward January
(`report monthly 2026-01`) exactly like one placed on 2026-01-05, and
the monthly listing stays in day order even when both date styles appear
in the same month.
