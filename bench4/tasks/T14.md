# T14 — Stock report for a single warehouse

The stock report totals everything together, so I can't answer "what is in
east right now?" without a calculator.

What I want:

- `report stock --warehouse NAME` shows, for each item, only the units in
  that warehouse, with line values priced on those units, and a total value
  for that warehouse alone.
- Items with nothing in the chosen warehouse are left out of the listing.
- API: `reports.stock_report(store, warehouse=None)` — passing a warehouse
  name filters to it; leaving it off keeps today's all-warehouse totals,
  same output shape as before.
- Asking about a warehouse that holds nothing just gives an empty listing
  (not an error).
