# T13 — Move stock between warehouses

Now that stock lives in two places we are constantly walking boxes from the
main room over to east, and I have no way to record it.

What I want:

- CLI: `transfer SKU QTY SRC DST` moves QTY units of SKU from warehouse SRC
  to warehouse DST. API: `Store.transfer(sku, qty, src, dst)`.
- You can never move more than the source warehouse actually holds. On an
  overdraw: print an error, exit with code 1, and leave the stored state
  completely untouched — same rule as shipping below zero.
- Transferring an unknown SKU is an error (exit 1).
- A successful transfer changes only the two warehouses involved; the
  item's total quantity stays the same.
