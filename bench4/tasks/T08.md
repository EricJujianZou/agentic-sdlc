# T08 — Bug: stock totals doubled after importing a supplier CSV

We imported our supplier's stock list with `import-csv` and afterwards
`report stock` shows TWO rows for some items, with the total value
roughly doubled for those. Looking closely, each doubled item appears
once with the SKU the way we write it (`WID-1`) and once the way the
supplier's file spells it (`wid-1`).

SKUs are not case sensitive — `wid-1` IS `WID-1`. We always write ours
in uppercase; the supplier's export tool lowercases them, and some of
their files even mix both spellings of the same SKU.

Expected: importing a file that spells a SKU in a different case updates
the existing item instead of creating a second one; we never end up with
two entries differing only by letter case (even when the file itself
mixes cases); and SKUs come out uppercase in listings and reports, the
way we write them.
