# T28: Invoice files we can send out

The on-screen invoice breakdown is handy but we need something we can attach
to an email and re-generate later:

- `invoice <order-id> --output <path>` writes the invoice as a plain-text
  file at that path (printing to the screen as well is fine).
- The file contains the order id, the SKU, the quantity, the order date, and
  the same labeled breakdown as on screen — subtotal, discount, tax, total —
  in the standard money format.
- The layout must be deterministic: generating the invoice for the same
  order twice produces byte-identical files. No generation timestamps or
  anything else run-dependent.
- Without `--output` the command behaves exactly as before. Unknown order
  id: exit 1 and no file gets written.
