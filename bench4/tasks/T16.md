# T16 — Backups

I fat-fingered an import last week and had no way back. I want cheap
insurance built in.

What I want:

- `backup`: snapshot the current state. The backup lives next to the state
  file in the data directory and is named `<state-file-name>.bak-<STAMP>`
  where STAMP is a timestamp that is safe in filenames on any OS (so no
  colons). The command prints the backup name it created.
- `list-backups`: print the existing backup names, one per line, oldest
  first. No backups is not an error (exit 0).
- `restore NAME`: bring the state back to exactly what the named backup
  captured. NAME is a name as printed by backup/list-backups. Restoring a
  name that does not exist: error, exit 1, nothing changes.
- Round-trip guarantee: backup, make changes, restore — every report then
  reads exactly as it did at backup time.
