# T25: Per-category discount rules

We negotiate discounts by product category and need somewhere to keep the
rules. Just the bookkeeping for now — applying them to order pricing is a
separate ask:

- `set-discount <category> <percent>` creates or replaces the rule for that
  category. Percent is 0 to 100, decimals allowed (`12.5` is fine); anything
  outside that range is a user error (exit 1).
- `list-discounts` prints each category with its percent, one per line.
- `remove-discount <category>` deletes the rule; removing a category that
  has no rule is a user error (exit 1).
- Rules persist in the state file like everything else, so they are still
  there on the next run.
- Library side: `store.set_discount(category, percent)` (raises ValueError
  for an out-of-range percent), `store.get_discount(category)` returning the
  percent or 0 when there is no rule, and `store.remove_discount(category)`.
