# T12 — Track stock per warehouse

We rented a second warehouse ("east") alongside the main room, and I need to
know what is sitting where — without breaking anything that thinks in
totals.

What I want:

- `receive` and `ship` accept `--warehouse NAME` (default `main`).
  Same for the API: `Store.receive(sku, qty, warehouse="main")` and
  `Store.ship(sku, qty, warehouse="main")`.
- An item's overall quantity — `item.qty`, every report, CSV export — stays
  the total across all warehouses, exactly like today. New:
  `item.qty_in(name)` returns the count in one warehouse (0 if it has never
  held that item).
- Creating an item with a starting quantity (`Item(qty=5)`,
  `add-item --qty 5`) puts that stock in `main`. Receiving a purchase order
  stocks `main` too.
- State file: bump the version to 3, and store each item's quantity broken
  down per warehouse. Version-2 files and old unversioned files must still
  load, with all their stock landing in `main`; the next save writes the new
  layout.
- Reports keep their current output shape (totals, not per-warehouse).

Acceptance criteria: receive/ship with `--warehouse` affect only that
warehouse, totals stay consistent everywhere, and every state file we have
ever written still loads.
