# T42 — Batch apply from CSV

Every Monday we key in dozens of stock movements from the weekend paper
sheets. Typing them one command at a time is slow and, worse, when a typo in
the middle fails we are left half-applied and have to puzzle out where we
stopped.

Please add `stockroom --data DIR batch FILE.csv` that executes a list of
operations all-or-nothing:

- The file has a header `op,sku,qty,warehouse,to_warehouse`. Supported ops:
  `receive`, `ship`, `transfer`. An empty warehouse cell means "main".
  `transfer` moves qty from `warehouse` to `to_warehouse` (a brand new
  destination warehouse is fine).
- Rows are applied in order. If EVERY row succeeds, the changes are saved
  and it prints `applied N operations`, exit 0.
- If ANY row fails (unknown op, unknown SKU, shipping or transferring more
  than is on hand, bad qty), nothing at all may be applied — the data must
  be exactly as it was before the command — and it prints
  `error: batch failed at row N: <reason>` on stderr (data rows numbered
  from 1, the header does not count), exit 1.
