# T01 — Item categories

We organise the stockroom by shelf area (tools, fasteners, adhesives, ...)
and want the software to know about it.

- `add-item` gets an optional `--category NAME`. Items created without one
  get the category `uncategorized`.
- The category is saved with the item and survives restarts. In code,
  `Store.add_item(...)` accepts a `category=` keyword and `Item` records
  carry a `category` attribute.
- The stock report can group by shelf area: `report stock --by-category`
  prints the rows under one heading per category. In code,
  `reports.stock_report(store, by_category=True)` returns a dict with
  `"categories"` (mapping category name -> the usual row dicts for that
  category, rows sorted by SKU) and the overall `"total_value"`.
  The plain `report stock` / `stock_report(store)` keeps working exactly
  as before.
- CSV export gains a `category` column carrying each item's category.
