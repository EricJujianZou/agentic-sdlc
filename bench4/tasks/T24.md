# T24: One way to print money

Money shows up all over our reports and no two places format it quite the
same. Give us a single formatter and use it everywhere:

- New module `stockroom.money` with a function `format_money(amount)` that
  returns a string like `"$19.99"`.
- An `int` amount means cents: `format_money(1999)` is `"$19.99"`,
  `format_money(5)` is `"$0.05"`. A `float` means dollars:
  `format_money(3.5)` is `"$3.50"`.
- Always a leading `$`, always exactly two decimals, no thousands
  separators. Negative amounts come out as `-$X.XX`.
- Every money figure printed by the CLI reports — stock report line values
  and total, price-change amounts, and any money we print from now on —
  goes through this formatter. No bare `19.99`-style money should appear in
  report output any more.
