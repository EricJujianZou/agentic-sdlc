# T10 — Who did that?

Three of us share the stockroom terminal and we can never tell who last
touched a record. Please let commands record who ran them.

- Every command that changes state (`add-item`, `add-supplier`,
  `receive`, `ship`, `place-order`, `receive-order`, `cancel-order`,
  `import-csv`) accepts an optional `--actor NAME`.
- When a command creates or modifies an item or an order and `--actor`
  was given, that record's `last_actor` is set to the name and saved
  with the record. Each later change with an actor overwrites it, so it
  always reflects the most recent change.
- Without `--actor` everything keeps working as before; records that
  have never had an actor recorded have a `last_actor` of None.
