# T26: Order totals and invoices

We need to know what an order actually costs once discounts and tax are in
the picture:

- `reports.order_total(store, order_id)` returns a dict with keys
  `subtotal`, `discount`, `tax`, `total`, all in dollars:
  - subtotal = order quantity x the item's current unit price
  - discount = subtotal x the discount percent for the item's category
    (the category discount rules you added; no rule means no discount)
  - tax = (subtotal - discount) x the flat tax rate
  - total = subtotal - discount + tax
- The tax rate is a percent kept in the state as configuration, default 0.
  New CLI command `set-tax-rate <percent>` sets it.
- New CLI command `invoice <order-id>` prints a breakdown with the four
  labeled amounts (subtotal, discount, tax, total) in the standard money
  format. Unknown order id: the usual error and exit 1.
