# T09 — Search

With a few hundred items in the store, finding one currently means
exporting to CSV and using a spreadsheet. Please add search.

- `reports.search_items(store, query)` returns the items whose name OR
  SKU contains the query, case-insensitively ("widget" finds
  "Steel Widget"; "gad" finds GAD-1). Results are a list of dicts with
  at least `sku` and `name`, sorted by SKU. No matches -> empty list.
- CLI: `search QUERY` prints one line per match including the SKU and
  the name. It exits 0 whether or not anything matched.
