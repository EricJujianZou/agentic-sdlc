# T05 — Old CSV files must still import now that we have categories

Since the category support you added, our exports carry a `category`
column. But we have a drawer full of older exports, and our suppliers
still send stock lists in the old layout without that column.

- `import-csv` accepts both layouts:
  - files WITHOUT a `category` column import fine, and those items get
    the category `uncategorized`;
  - files WITH a `category` column keep the category given in the file.
- A file exported today and imported into an empty store reproduces the
  same categories.
- Exports keep including the `category` column as they do now.
