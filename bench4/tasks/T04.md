# T04 — Don't let us ship stock we don't have

Today someone ran `ship WID-1 10` when we had 3 on the shelf, and the
system happily recorded -7 on hand. The shelf can't go negative.

- Shipping more than the current on-hand quantity must be refused: the
  CLI prints an error and exits with code 1, and `Store.ship(...)`
  raises `ValueError`.
- A refused shipment leaves everything untouched: the item's quantity is
  unchanged and nothing is written to disk.
- Shipping exactly the on-hand quantity (taking it down to zero) is
  still allowed.
