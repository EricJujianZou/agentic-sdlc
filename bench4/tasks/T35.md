# T35: Undo the last change

Fat-finger insurance: a plain `stockroom --data <dir> undo` should reverse the
most recent change and save. Running `undo` again steps back one more change,
and so on.

Acceptance criteria:
- At least these are undoable: add-item (the item is removed again), receive
  (the quantity comes back down), ship (the quantity is restored), transfer
  (moved back), place-order (the order is gone), cancel-order (the order is
  pending again), set-price (the old price is back).
- Two undos in a row reverse the two most recent changes, newest first.
- When there is nothing left to undo, `undo` is a user error: exit code 1 and
  nothing is modified.
- Undo works from the history of changes recorded with the data, so it also
  reverses changes made in an earlier session.
