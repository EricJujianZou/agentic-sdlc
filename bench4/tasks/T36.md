# T36: One-shot scheduled reordering

Every morning someone reads the low-stock report and types the same purchase
orders in by hand. Automate it: `scheduled-reorders --as-of YYYY-MM-DD
[--threshold N]` places a pending purchase order for every current reorder
suggestion (same logic and same default threshold as `report low`), dated with
the as-of date and for the suggested quantity.

Acceptance criteria:
- Each suggested sku gets exactly one new pending order, quantity equal to the
  suggested quantity, order date equal to the as-of date.
- Items with no supplier, or items that are not low, get no order.
- Running the command again for the same as-of date must not create duplicates:
  once a sku has been auto-ordered for a given day, that day is done for that
  sku. (Freshly placed orders are pending, so they also count against the next
  round of suggestions.)
- The command prints what it ordered (or that nothing was needed) and exits 0
  either way.
