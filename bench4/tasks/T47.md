# T47 — Summary dashboard

Management wants one screen with the day's numbers instead of running five
separate reports. Add `stockroom --data DIR report summary` printing, each
on its own line:

- `valuation: $X.XX` — total inventory value across all warehouses, exact
  to the cent, using the same money formatting as the other reports.
- `low stock (threshold 5): SKU1, SKU2, ...` — the items at or below the
  threshold (the same set the low-stock report shows), sorted by SKU;
  optional `--threshold N` overrides the default of 5.
- `pending orders: N` — how many orders are currently pending.
- `top category: NAME` — the category with the most units shipped overall
  (blank/none when nothing was ever shipped).
- `events: N` — how many entries the activity history holds.

Exit 0. It is a report: it must not modify anything.
