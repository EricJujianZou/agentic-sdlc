# T15 — Reorder suggestions keep ignoring orders already on the way

We keep double-ordering. When a purchase order is already pending for an
item, the reorder suggestions still suggest the full top-up as if nothing
was coming, so whoever reads the report orders it again.

What I want:

- Reorder suggestions must subtract units already on the way: with
  threshold T, quantity on hand Q, and P units on that item's orders still
  marked pending, suggest `max(0, T - Q - P)`.
- If that works out to 0 — the pending orders already cover us — drop the
  item from the suggestion list entirely.
- Orders that were received or cancelled count for nothing; only pending
  ones.
- Everything else about the report (which items qualify, who to order
  from) stays as it is.
