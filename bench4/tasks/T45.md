# T45 — fsck: consistency check

After a bad sync we discovered an order pointing at an item that does not
exist, and last year a bug briefly drove a quantity negative. We would like
a health check we can run from cron:

`stockroom --data DIR fsck`

- Cross-checks the data: orders referencing unknown SKUs, negative
  quantities in any warehouse, activity entries referencing unknown SKUs,
  and similar dangling references.
- Prints one line per finding, starting with `problem:` and naming the
  offending order id / SKU (a negative-quantity finding should say
  "negative").
- Exits 2 when anything is found; exits 0 when clean and prints `fsck: ok`.
- It is a check only: it must never modify the data, no matter what it
  finds.
