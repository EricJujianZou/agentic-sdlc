# T21: Track price changes

We adjust unit prices a few times a year and by now nobody can say what
anything cost last quarter. Please add price tracking:

- New CLI command `set-price <sku> <price> [--date YYYY-MM-DD]` updates the
  item's unit price (`--date` defaults to today). Unknown SKU: the usual
  error message and exit code 1.
- Every change is remembered on the item itself: each item carries a
  `price_history` list, and each set-price appends an entry
  `{"date": ..., "old": ..., "new": ...}` with the old and new price in
  dollars. History is saved with the rest of the state. Items whose price
  never changed just have an empty history.
- In the library the same thing is `Store.set_price(sku, price, date=...)`.
- A new report — `report price-changes` on the CLI,
  `reports.price_changes(store)` in the library — lists every recorded change
  across all items, oldest first (sorted by date). `price_changes` returns a
  list of dicts with keys `sku`, `date`, `old`, `new`; the CLI report shows
  the date, SKU and both prices, with prices printed to two decimals.
