# T27: Low-stock list and reorder suggestions disagree

Item WID-7 has quantity exactly 5. When I run the low report with threshold
5, WID-7 shows up in the low-stock list, but the reorder suggestions printed
right underneath skip it — even though the item has a supplier. Items a bit
below the threshold show up in both. This makes the suggestions
untrustworthy: I page through the low list, see something flagged, and then
there's no suggestion telling me how much to order.

Whatever the intended rule at the exact threshold is, the two views have to
agree with each other — in the report command and in the library functions
alike. If an item is flagged as low and it has a supplier, I expect a
suggestion row for it; an item flagged as low with no supplier obviously
still gets no suggestion.
