# T37: Weekly shipment report

We plan pick-up rounds by week, not by month. Give us shipping numbers per ISO
week:

- `report weekly` prints the total units shipped per ISO week, labelled like
  `2026-W28` (ISO week-numbering year, zero-padded two-digit week), oldest week
  first. Exit 0.
- Only weeks in which something actually shipped appear.
- Library: `reports.weekly_shipments(store)` returns a dict mapping the week
  label to the total units shipped in that week. It works off the shipment
  dates already recorded when goods leave (`ship ... --date`), so a shipment
  dated `2026-01-05` counts toward `2026-W02`.
