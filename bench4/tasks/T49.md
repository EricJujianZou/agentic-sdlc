# T49 — Full export / import (archive)

We want a single-file snapshot we can attach to an email, restore onto a
laptop, and keep as an off-site backup — everything: catalogue, suppliers,
all warehouses, orders, settings AND the activity history.

- `stockroom --data DIR export-archive FILE` writes one self-contained JSON
  file. Exit 0.
- `stockroom --data DIR import-archive FILE` into an EMPTY data directory
  recreates the whole state. Importing into a directory that already
  contains data must refuse with exit 1 and change nothing.
- Acceptance: after exporting from A and importing into a fresh B, every
  report run in B prints exactly what it prints in A — stock, order
  history, monthly, summary; quantities, money, event counts, all of it.
