# Arm B kickoff — one session, all instances

Solve ALL 20 SWE-bench instances in `bench2/manifest.json`, in the exact
order of the ordering named in your kickoff prompt (`.orderings` in the
manifest), all within this single session.

For each instance, follow `bench2/instructions_per_instance.md` (setup,
rules, patch format, result recording). Your run id and work branch are in
your kickoff prompt.

That is the whole task. Work through the list however you see fit.
